# libmona

`libmona` は、Monacoin のトランザクション作成および署名を行うためのライブラリです。

Monacoin Core などのノードソフトウェアを起動できない環境でも、トランザクションの作成、電子署名の生成、ならびに署名の検証を行うことができます。

本ライブラリは Electrum-mona を参考に実装しており、Monacoin ネットワーク上で動作確認を行っています。
